# AI Web Briefing Hub

一个给 ChatGPT 网页端、Codex、Claude Code 和 DeepSeek Harness 共用的私有项目资料库。

## 最短工作流

1. 在网页端说清楚要做什么。
2. 把确定的需求写入 `00-inbox/` 或 `10-briefs/`。
3. 任一本地代理读取资料、执行任务，并把结果写入 `40-work/`。
4. 有重要取舍时，记录到 `50-decisions/`；需要转交时，更新 `60-handoffs/CURRENT.md`。

## 文件夹约定

| 位置 | 放什么 |
| --- | --- |
| `00-inbox/` | 尚未整理的网页端需求、附件说明、素材链接 |
| `10-briefs/` | 已确认的任务简报；一个任务一份文件 |
| `20-research/` | 调研、引用来源、对比和验证记录 |
| `30-specs/` | 需求、设计、流程与验收标准 |
| `40-work/` | 正在产出的可交付内容或子项目 |
| `50-decisions/` | 已做决定及其原因，防止代理重复讨论 |
| `60-handoffs/` | 给下一个工具或人的当前状态、下一步和文件入口 |
| `90-archive/` | 已完成或不再活跃的资料 |

数字前缀是排序规则：越靠前越先读。请保留该顺序。

## 命名

使用 `YYYY-MM-DD-主题.md`，例如：`2026-09-05-网站改版需求.md`。

敏感信息（密码、API 密钥、身份证件、私密原始数据）不上传。
