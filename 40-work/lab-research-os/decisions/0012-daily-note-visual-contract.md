# Decision 0012 · Future Daily Paper notes require evidence-bearing visuals

Status: approved by direct Human PI instruction, 2026-09-29.

Every newly created personal and supervisor Daily Paper note must include a source-visual section and a method/research workflow section. A useful source figure, table image, map, profile, spectrum or conceptual diagram must come from the same lawfully accessed full text and carry its original identifier, PDF page, source and inference boundary. The workflow is agent-drawn only from reported methods, evidence, model or reasoning steps and must identify its source sections/pages.

Reviews, models and non-experimental papers use the reported evidence/reasoning or model workflow rather than an invented experiment. If a complete paper genuinely has no useful source visual, the note records a bounded exception with the inspected pages/sections and still includes a workflow. Missing complete full text blocks the formal note. Another paper's image or an invented step is never an acceptable substitute.

The private Skill, output contract, recurring prompt and validator implement this standing requirement. New issues use the validator's visual-contract flag. Historical issues are not retroactively failed by the default validator; their separately authorized repair continues from its preserved checkpoint.
