## 先决边界

F4=INSUFFICIENT_EVIDENCE；拒绝正确性 UNKNOWN。F5/F6 是局部脚本的已定位缺陷。修复 F5/F6 只能改善测量和分类，不能被宣称消除了 CLI 拒绝。C1 尚未实际受测，不修“连续性”。

F4 责任清单：观察为 exec_command 进程创建前策略拒绝；原证据 worker.stderr；根因未知；可见责任边界为 CLI 执行／审批策略，非冻结 Foundation，具体规则未知；后果是无法获取恢复证据。最小提议仅是取得同一次历史拒绝的原始工具参数、有效策略来源／命中规则和评估解释；若历史记录不可得，明确保留 UNKNOWN，另行批准有观测能力的诊断设计，不能直接重试。风险是把当前配置误当历史配置，或为了取证扩大到无关会话／凭据。只读诊断无实现回滚项；保留新增证据并用新记录更正解释。必要后续检查是把原命令表示与原策略决策绑定；本轮未执行策略测试。没有足够依据提出任何策略修改。

## 最小有序流程

1. **另行授权后，先完成 F4 的定向只读取证**：仅原 thread/time window 的决策输入与有效策略；缺失就停止根因归因。不得改 sandbox、审批开关、全局配置或白名单。不存在因为命令看起来只读就应放行的通用规则。
2. **仅针对 F6 的已证实逻辑，准备单独派生实现**：明确区分 action / diagnostic / unknown，不再把“非四种已知类型”全部算工具动作。保持原错误、执行状态及未知类型；未知或缺观察仍禁止接收。只有观察到真实越界动作才用 action-based FAIL。C2 的“门槛运行完成”和“分类被验证正确”必须分开，不能仅凭没写文件认证 PROVEN。
3. **仅针对 F5 的已证实逻辑，准备单独派生组装**：送审前从实际流直接绑定字节数、hash、内容／编码和执行 receipt；投影要引用原流。缺失、截断、篡改、超限或保密冲突均明确阻止完整证据声明。不得修改原 AT05 prompt/response。
4. **运行下面限定的离线回归与负控**，捕获实际命令、退出码、原始 stdout/stderr、代码／输入哈希。合成负例标注为 synthetic，仅用于验证门槛，不能当作真实执行证据或成功审批。
5. **检查证据包完整性，再一次独立证据审阅**：包含诊断、差异、实际回归和负控；正常阈值仍是 PASS、confidence>=0.80、无未解决 consequential anomaly、completed、零工具调用。审阅的是执行证据；不声称亲自运行。失败／不确定就停，不换模型反复刷分。
6. **只有 F4 的正确策略路径有依据、局部修复被接收、回归和负控通过后，才申请／启用一份新 packet 的恰好一次 successor 验证**。审批拒绝仍是有效终态，不绕过。不能把仅修复 F5/F6 当成授权重复尚未解释的 F4 阻断。
7. 新验证最多一次；原始轨迹 → 机械检查 → 独立证据审阅 → 预声明 gate → 写回／保持 held → CAS checkpoint。没有 Astra 补充 PASS；FAIL／UNCERTAIN 均保留并停止。AT05 历史结论不重写。

以上所有实现修改、测试、模型调用及 successor 执行均需另行明确授权。步骤1不产生隐含的步骤2–7授权。当前只批准了本提案的生成。

## 有界回归／负控设计（均未执行）

| 案例 | 要验证的行为 |
|---|---|
| 原 AT05 error 事件＋缺失观察 | 保留 warning/error，action_count不增加；恢复NOT PROVEN；接收UNCERTAIN／不写回。不得变成PASS。 |
| 完整合法观察＋严格匹配候选＋合格独立审阅 | 只在所有事先声明的条件满足时允许写回；测试fixture不替代真实审阅。 |
| 实际拒绝／非零退出／超时 | 执行BLOCKED或失败被保留；不能因顶层CLI exit0推断命令成功；不得写回。 |
| 额外破坏性或越界动作 | FAIL／阻止写回；策略门槛仍保持原保护，不执行该动作。 |
| 未知事件、畸形事件、诊断＋真实动作混合 | 未知保持fail-closed；真实动作不被warning掩盖；顺序与归属可追踪。 |
| stderr非空／合法空／缺失 | 空流与未捕获分开；非空原文可审阅；缺失不能用空串冒充。 |
| 流篡改、编码异常、超限、合成秘密 | 不得声称完整byte-bound证据；记录原因并停止外发或接收。 |
| 审阅缺失／格式错误／低置信度／异常／工具调用 | 保持拒绝接收，阈值不变。 |
| stale checkpoint 或写回不等字节 | 停止并保留证据；不强制覆盖、不制造成功。 |

这些是最小门槛回归的提议，不构造通用策略框架，不重跑已接受 Foundation 测试。回归只触及未来派生的局部代码和隔离的临时输出。
