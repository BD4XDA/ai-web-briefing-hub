# 决策 · 每日论文作为首个 production/shadow workload

批准将现有“每日论文”会话和唯一 recurring task 接入 Lab Research OS。Daily 保留 Literature Radar、既有三篇精读合同和 Human PI Daily Research Brief；其他 readiness workload 采用 weekly、event、milestone 或 state trigger，除非另行批准，不创建新 schedule。

默认不用 Astra。日常发现、初筛和批处理使用 Luna/low-cost route；Sol 只承担有科学判断的精读与 QA；Astra 只处理结构性研究架构或后果重大的冲突。任何子任务必须显式声明 model class 与 effort，不得继承父任务最高推理等级。

日报频率固定为 daily，但日报只能汇总真实新信息、实际执行 workload 和最新 verified state。零变化是合法输出，不得用昂贵重算填充版面。
